# FELINONG 

## 📌 Descrição do Projeto
O FELINONG é uma plataforma dedicada à proteção, cuidado e adoção de gatos resgatados. 
Esta entrega final consolida todo o projeto, aplicando práticas profissionais de **controle de versão**, **acessibilidade**, **otimização para produção** e **documentação técnica**.

---

## 🛠 Tecnologias Utilizadas
- HTML5 / CSS3 / JavaScript
- Git / GitHub (GitFlow)
- Ferramentas de otimização de imagens (WebP, TinyPNG)
- Ferramentas de minificação e compressão de arquivos
- Ferramentas de acessibilidade (leitores de tela, contraste, navegação por teclado)

---

## ⚙ Estrutura de Versionamento (Git/GitHub)

Este projeto utiliza a **estratégia GitFlow**:

| Branch         | Função                                              |
|----------------|-----------------------------------------------------|
| `main`         | Produção                                            |
| `develop`      | Desenvolvimento principal                           |
| `feature/`     | Novas funcionalidades                               |
| `release/`     | Preparação para release                             |
| `hotfix/`      | Correção rápida em produção                         |

**Histórico de commits semântico:**
- `feat:` nova funcionalidade
- `fix:` correção de bug
- `docs:` documentação
- `chore:` manutenção ou ajustes internos

**Versionamento semântico:**  
Ex.: `v1.0.0`, `v1.1.0`, `v2.0.0`

---

## ♿ Acessibilidade (WCAG 2.1 Nível AA)
O projeto garante:
- Navegação completa por teclado.
- Estrutura semântica adequada (`<header>`, `<main>`, `<section>`, `<footer>`).
- Contraste mínimo de 4.5:1 para textos normais.
- Suporte completo para leitores de tela.
- Versão de **alto contraste** e **modo escuro acessível**.

---

## 🚀 Otimização para Produção
- Minificação de CSS, JS e HTML.
- Compressão e otimização de imagens (WebP e TinyPNG).
- Código limpo e pronto para deploy em ambiente de produção.
